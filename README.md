# Autocolante Nucată · familia Costenco

Autocolantele pentru căsuța familiei Costenco de la serbarea de toamnă din
Larga Nouă: brâul de jos, chenarul și dantela geamurilor, scoarța, ștergarele,
emblema și frizul de sub tavan.

Pagina pentru aprobare: https://vladimirmalii.github.io/nucata-autocolante/

Fișierele de tipar sunt în `tipar/`, la dimensiunea reală (1 unitate = 1 mm).
La emblemă, textul se transformă în contururi înainte de tipar.
